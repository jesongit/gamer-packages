# Gamer 配置包

用于分发 Gamer 配置包的公开仓库。正式目录通过 GitHub Releases 提供，代码仓库无需保存每个配置文件。

## 使用配置

当前正式目录提供 `hsr 1.0.2`（云星铁），修复挑战次数为 3 时的 OCR 裁切，并在历战余响周次数耗尽后切换默认侵蚀隧洞。保留 1.0.1 的副本数值 OCR 修复和原直播调用脚本。

在 Gamer 0.4.0 或更高版本安装配套的自动化插件，然后在「配置包」页添加仓库：

https://github.com/jesongit/gamer-packages

刷新后选择配置安装。下载者不需要 GitHub 登录或 gh。覆盖已有同 ID 配置会替换本地内容，请先导出需要保留的修改；安装后不会自动运行脚本。

## 发布配置

在运行 Gamer 的电脑上安装 GitHub CLI 并用有仓库写权限的账号登录。安装「配置包发布」插件后，在工作台选择本地配置，填写仓库地址，生成预览、创建草稿并确认公开。已有导出文件先在配置包页导入。

插件为每次 Release 生成完整 packages.json、.gamerpkg 归档和 SHA256SUMS.txt。未选择的已发布配置会保留。同 ID、同版本内容不能改写；更新内容请先提升配置版本。

首次仅支持公开仓库。多人发布需协调，避免同时操作。发布后 GitHub 匿名发现可能短暂未同步，可稍后刷新。

云游戏日常在进入战斗后依次确认二倍速和自动战斗；只有识别为关闭时才点击，并重新截图确认。1.0.2 在读取消耗前和每轮战后双读周次数，零次为有效值；耗尽后关闭挑战页、打开指南、确认生存索引和侵蚀隧洞标题，再继续执行。单批挑战不超过实际剩余周次数。

1.0.2 与先前 1.0.2-test.2 的脚本和模板字节一致。候选曾通过 Windows/Linux 各 41 项 OCR 场景（27 项可用真实帧场景、14 项合成边界）、23 项有状态周次数流程、48 项入口回归和 26 项探针单测；已缺失的 14 张旧截图未计入。正式包通过隔离 Core 的导入、覆盖、哈希拒绝和可复现导出。上述检查不替代真实账号上的导航、战斗、切换副本或完整日常验收。

旧配置目录及验收示例已下架；本地已有配置不受远端目录清理影响。
